# 🐉 Dragon Heads on Death Datapack

Датапак для Minecraft 1.20.1, который заполняет весь инвентарь игрока головами дракона после его смерти.

## 📋 Требования
- **Minecraft версия:** 1.20.1
- **Тип сервера:** Single Player / Multiplayer
- **Требуемые разрешения:** Datapacks (должны быть включены)

## 📦 Установка

1. Скачайте датапак
2. Откройте папку вашего мира: `.minecraft/saves/[World Name]/datapacks/`
3. Поместите папку `dragon_heads_datapack` в папку `datapacks`
4. Перезагрузите мир или выполните команду: `/reload`

## 🎮 Использование

Просто играйте! Когда вы умрёте:
- Инвентарь заполнится головами дракона (7 стопок по 64 шт = 448 голов)
- Вы увидите красное сообщение: "💀 Ты умер!"
- Золотое сообщение: "🐉 Инвентарь заполнен головами дракона"
- Чат покажет: "Ты собрал 448 голов дракона!"

## 📝 Структура датапака

```
dragon_heads_datapack/
├── pack.mcmeta                    # Метаинформация датапака
├── README.md                      # Этот файл
└── data/
    ├── minecraft/tags/function/
    │   ├── load.json              # Загрузка при старте
    │   └── tick.json              # Выполнение каждый тик
    └── dragon_heads/
        ├── function/
        │   ├── load.mcfunction    # Инициализация
        │   ├── tick.mcfunction    # Проверка смертей
        │   └── on_death.mcfunction # Выдача голов
        └── advancement/
            ├── root.json          # Корневой адванс
            └── on_death.json      # Адванс смерти
```

## ⚙️ Кастомизация

### Изменить количество голов:
Отредактируйте `data/dragon_heads/function/on_death.mcfunction` и измените количество команд `give` или значение в скобках.

Пример для 100 голов:
```
give @s dragon_head 64
give @s dragon_head 36
```

### Изменить предмет:
Замените `dragon_head` на любой другой предмет (например, `diamond`, `netherite_block`).

### Отключить уведомления:
Удалите строки `title` и `tellraw` из `on_death.mcfunction`.

## 🐛 Решение проблем

**Датапак не работает:**
- Проверьте, что датапаки включены (`/datapack list`)
- Перезагрузите датапак: `/reload`

**Нет уведомления после смерти:**
- Убедитесь, что `tick.mcfunction` выполняется
- Проверьте, что скорборд `dh_death` активен
